# Screenshots to capture

Save PNGs in this folder using these names, then reference them in the main README.

1. `home.png` – Home page (desktop)
2. `projects.png` – Projects page
3. `contact-form.png` – Contact form filled in
4. `mobile.png` – Any page at phone width (browser DevTools, device toolbar)
5. `mongodb-atlas.png` – The `messages` collection in MongoDB Atlas showing a saved submission
6. `deployed.png` – The live Vercel URL in the browser
